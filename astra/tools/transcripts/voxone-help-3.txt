With Feature Codes you are able to manage your extension within the PBX without the need to login. You will manage this via various shortcuts in your terminal and/or mobile device. Call forwarding. Direct: All incoming direct calls get forwarded to the specified number. Direct Activate: *21*<number># Deactivate: #21# Delayed: All calls are forwarded to the specified number after a certain time (in case there is no answer). Delayed Activate: *61*<number># Deactivate: #61# When busy: All incoming calls you receive when you are busy get forwarded to the specified number. When busy Activate: *67*<number># Deactivate: #67# Activate a profile. You can activate your profiles via shortcuts and profile numbers. To find which profile number each profile has, go to the Voxone app on your computer or use the browser version, then go to Settings > Profiles. At the bottom of the page click Display profile numbers. If you do not specify a time for activating the profile via Feature Codes, the profile's default time will be activated. Activate: *24*<profile number>[*time]# Deactivate: #24# The profile duration can be typed in the following ways: 1 digit means x amount of days to come (0 means that the profile stays the same until you change it) 2 digits mean x amount of hours to come (if you want to set the profile active for less than 10 hours, you need to start the digit with a 0) 3 digits mean x amount of minutes to come (if you want to set the profile active for less than 100 minutes, you need to start the digit with a 0)Voxone help article from VOIP Unlimited: Use feature codes. Page 2 of 3. 4 digits are read as a timestamp for the ongoing day (the two first digits are the hours, and the two last are minutes). If the time has passed already, this means the timestamp for the following day. 6 digits are read as a date (two first digits are the year, the two middle ones are months, and the last two the days). Queuing systems. You have the option of logging into your various queues. You can only log in and out of queues that you are already a member of. If you are not a member of a queue and try to log in with Feature Codes, you will get a message that says, "The service is not active". Log in: *75*<queue number># Log out: #75*<queue number># Call pick up. If one of your colleagues receives a call and you wish to pick up the call immediately before they answer it, you can do so. You can only do this on incoming direct calls to your colleagues. *80*<number> In the shortcut above, the <number> stands for the number or short number the call is picked from. Hide outbound CLI. If you want to call with a hidden number, you can use Feature Codes to activate this if necessary. *31*<number> In the shortcut above, the <number> stands for the number you want to make a call to. Redirect ongoing incoming calls. If you have an ongoing call where someone called you, you can transfer this call to another number. Only incoming calls can be forwarded, outgoing calls cannot be forwarded. You have the option to transfer the call directly or, alternatively, do an attended transfer. It takes a few seconds before the transfer takes place when you type in the command. The default setting for call forwarding that you have on your user, determines how this forwarding will work. An administrator can adjust this in the admin portal under Users > Other settings > Call forwarding. You can choose from the methods below: Notified (Attended) transfer: You have the opportunity to talk to the person you connect to before completing the transfer. Direct transfer: You do not get the opportunity to talk to the person you are transferring to. The call will be connected directly. None: Calls are not forwarded. #<number># In the shortcut above, the <number> stands for the number or short number you want to transfer the call to. If you want to take the call back, press *. End the call to complete the transfer.Voxone help article from VOIP Unlimited: Use feature codes. Page 3 of 3. Directly to voicemail. If you have an ongoing call, you can transfer the call directly to a colleague's voicemail if the person wants to leave a message. *59*<number># The call is directed to the voicemail which is owned by <number>. Also, short numbers can be used in this shortcut. Bypass. You have the opportunity to call your colleagues and bypass all call routing, referrals and call forwardings. For example, your colleague may have the lunch profile active. Then you have the option to call through this reference or forward the call to reach the person. *60*<number># By using the bypass shortcut, it means you can go by any call routing. Each user that wishes to use the co-listening feature will need to have a CC Pro license added to their account. Please be aware that each party (i.e. the listener and the user being listened to) will need CC Pro. Please note that co-listening does not currently work with the Voxone mobile app. Once the correct licenses have been assigned, the co-listening feature will be unlocked. In order to listen in to a call, simply identify the user who's call you wish to listen to within the Voxone softphone app and then click the call icon next to their contact record. Select the 'Listen in' option to listen to their call. After selecting this option, the colleague that you are listening in to will hear a beep, alerting them that co-listening is active.Voxone help article from VOIP Unlimited: Use feature codes; Use co-listening. Users with the Recorded calls User Permission will be able to access their calls from the call history section. N.B. users with this permission will not be able to delete any call recordings. Supervisor Permissions allow a user to access, download and delete all of the call recordings for a group of users via the Voxone admin portal. Selecting the everyone group will give that user access to all of the call recordings for that Voxone instance, or you can click on the drop down to give access to a specific group. Managing call recordings from the admin portal. If a user has Supervisor Permissions, the Recorded Calls section will be available to them on the left hand side when they log in to the admin portal. Here, users can select a specific user to search for by using the Users/PBX services filter in the flyout on the left. The Counterpart filter allows you to search for a specific phone number that isn't a user or PBXVoxone help article from VOIP Unlimited: Enable and control call recording; Find, download or delete recordings. N.B. for this filter to match you must prepend 00 and the country code to the phone number you want to search for, e.g. to search for calls to the UK number 01202612000 you will need to input 00441202612000 to the filter. The Time period allows you to search for a specific or custom date range. Call Length filters for calls of a specific length. The Inactive Numbers filter allows you to search numbers on the instance that aren't currently assigned to a PBX service or user. Once you have set the desired filters, click the search button and the results will appear in the pane to the right. To listen to, download or delete a recording, tick the box next to the recording and select the desired action in the fly-out on the right.
