Broadband Installation Types (Openreach Business Standard).
Openreach 'Business Standard': We've expanded our installation options to give you more flexibility in delivering broadband services to your customers. Premium and Advanced Installs go beyond managed installations, allowing engineers to install equipment deeper into the premises and provide additional service enhancements.
Available Installation Types for Fibre Broadband.
Managed Broadband Installation. Key features: Up to 10 meters of internal wiring can be installed from the lead-in point. The NTE is installed within 1 meter of a 13A power socket. Ensures that the wiring complies with Openreach standards for the router provided by Connect CP. Connect 1 device.Show the functioning service to a responsible adult, such as a householder or proprietor.
If the minimum install type of Managed Install is selected and the site is classed as Premium Install by Openreach, the order will auto correct to Premium Install mid-flight and the additional cost will be billed.
Premium Broadband Installation. Key features: Install NTE at a distance of up to 30 meters from the lead-in, particularly in more challenging locations. On existing cable tray. In existing trunking. In accessible ceiling and floor voids (a thorough risk assessment by an engineer is required). Install up to 2 data extension kits. No router install (at own risk). Add voice reinjection plate and connect to a partner-provided cable as and when required.
Advanced Broadband Installation. Key features: The wiring can extend up to 100 meters from the point where the Openreach network connects to the premises. More complex cabling. Through multiple walls. On existing cable trays running horizontally or vertically using cable ties (may include through multiple floors). Through ceiling or floor tiles that are removable and accessible. Using in-situ cabling (structured) to provide service.
If the install type is selected as Managed Install or Premium Install and the correct install type is deemed as Advanced Install the order will fall into delay and the order will present the below delay:"Site Visit Reason provided does not cover the scope of work required. Site Visit Reason Advanced is required. Please amend or cancel the order as appropriate. If you do not respond before [date] then the order will be cancelled".
At this point, please contact our Broadband Provisioning support desk to confirm if you wish to proceed with the order as an Advanced Install.
When are premium and advanced installs available?
Premium and Advanced Installs are available to order immediately. Simply select 'Premium Managed Install' or 'Advanced Managed Install' from the Install Type options within the Gamma Portal, when placing your order. Further details and a demonstration of these steps can be found within the Broadband Accreditation's 'Provisioning Broadband' section.
Prices: Prices for the respective installation types can be located on the Broadband Price list, available via the Gamma Portal's 'Billing' homepage.
Business Standard FAQs.
Q: What are the price differences? A: The Broadband price list will always have the latest up-to-date pricing. The price list can be found on the Gamma Portal's Billing Homepage.
Q: How can I find the right install type for my site? A: To help ensure that you are selecting the right premise type for your customer, Gamma have created a spreadsheet that contains every Openreach site type along with the required install type.The spreadsheet is available on the Gamma academy by navigating to Knowledgebase > Connectivity > Broadband > Broadband Forms.
Q: When should an install type be considered? A: Install type is only required when a managed install is needed such as a new line installation. Managed, premium and advanced installs are not applicable for migrations or re-grades.
